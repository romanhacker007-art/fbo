# fbo

Навык для планирования, создания и проверки FBO-поставок Ozon: направления, даты сдачи, состав и грузоместа, продолжение после ошибок и подготовка отчётов.

Навык содержит инструкции для агента. Для фактической работы нужен отдельно настроенный авторизованный инструмент доступа к Ozon; установка этого репозитория не подключает кабинет и не измеряет скорость работы.

## Установка в Codex

Скопируйте каталог `fbo` в каталог навыков Codex, например `~/.codex/skills/fbo`, и перезапустите клиент для обнаружения. Используйте `$fbo` или опишите задачу создания поставок.

Состав: [инструкции навыка](fbo/SKILL.md), [процесс и продолжение](fbo/references/workflow.md), [производительность и отчёты](fbo/references/performance.md).
